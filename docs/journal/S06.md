## 1. 做了什么

**S6a（气泡层本体，已落地）**
- 新增 `DSHPetBubble.h/.m`：深色圆角 `UIView` + `UILabel`，宽上限 `min(宿主宽 × 0.74, 330pt)`，默认摆宠物头顶，头顶放不下自动落到下方，左右夹在 `8pt + safeArea` 内，点一下收起，6.5s 自动淡出。
- `DSHPetOverlay` 在 `setupBubbleInRoot:` 里建气泡并接两条通知：
  - `DSHPetSayNotification`（`userInfo.text`）→ 显示一条消息；
  - `DSHPetStatusNotification`（`userInfo.state`）→ 仅当 `bubbleStatusEnabled` 为真才播报工作状态（`working→干活中…`、`thinking→在想…`、`idle→闲着呢`）。
- 气泡位置在 `anchorBubble` 里用 `[_box convertRect:toView:]` 换到宿主坐标系，随宠物移动/旋转重锚。

**S6b（接 `/state` + 交互，本次落地）**
- `DSHPetBridge.h/.m`：`NSURLSession` ephemeral，轮询 `{base}/dsh-pet-7340/state?since=<lastCounter>`，默认 2.5s；可选 `X-DSHPet-Token` / `Authorization: Bearer`。只读红线不变：**永不调 `/quit`、不写 `/config`、不碰 `/ws/mobile`**。
  - `sections.workStatus.data.state` → `DSHPetStatusNotification`；
  - `sections.notify.data.event.data.text` → `DSHPetSayNotification`，用 `notify.counter` 去重；
  - 连续失败按每 20 次记一条 `bridge/fail`，不刷日志。
- 气泡文本清洗 `DSHPetCleanBubbleText()`：`\r\n`→`\n`→空格、去 `\u200b`、`\t`→空格、连续空格压成一个、首尾 trim、**超过 240 字截断**（超长日志不许撑爆气泡、不许拖慢排版）。
- 三行装不下 → 可点开全文：`showText:` 里用 `boundingRect` 量出真实高度，超过 `font.lineHeight × 3` 才置 `expandable`。第一次点击展开（`numberOfLines = 0` + 取消自动收起计时），第二次点击才收起；短句仍是点一下收。
- 展开态高度上限 = 宿主高 × 55%，超了夹住并尾部省略——防止一条超长文本把宠物整个人盖住。

## 3. 决定

- 气泡**不复用**宿主的 markdown 渲染：只做纯文本 + 清洗，避免气泡里出现一半语法符号一半渲染的怪相；要在手机上读全文，点开气泡即可。
- 气泡是「附加物」不是「必需品」：`bubbleEnabled` 关掉后 `Say` 通知直接丢弃，不排队、不补发。
- `/state` 轮询走 `since=counter` 而不是全量拉：宿主的 `counter` 单调递增，拉增量最省电，也天然避免重复播报。
