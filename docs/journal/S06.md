## 3. 决定

- 气泡**不复用**宿主的 markdown 渲染：只做纯文本 + 清洗，避免气泡里出现一半语法符号一半渲染的怪相；要在手机上读全文，点开气泡即可。
- 气泡是「附加物」不是「必需品」：`bubbleEnabled` 关掉后 `Say` 通知直接丢弃，不排队、不补发。
- `/state` 轮询走 `since=counter` 而不是全量拉：宿主的 `counter` 单调递增，拉增量最省电，也天然避免重复播报。

## 7. S6c 多开落地（2026-11-18）

### 7.1 为什么不把 Overlay 改成实例池

方案文档最早写的是"DSHPetOverlay 从单例改成实例池"。真正动手时否掉了：
Overlay 身上挂着窗口、气泡、旋转重排、safeArea 夹取、尺寸持久化、物理与手势，
这些在真机上被 20 多个版本验证过。把它拆成 N 份，等于把最稳的一段代码重写一遍，
风险全落在"多开"这个还不确定用户到底要不要的功能上。

真实做法：**主宠不动，第 2..N 只另起一套轻对象**。

- `DSHPetPet`：一只额外宠物。自带
  `DSHPetPlayer`（自己的 contentLayer）/ `DSHPetAnimator`（自己的动作抽签）/
  自己的手势 / 自己的物理状态。位置不落盘。
- `DSHPetCrew`：管家。一个 accelerometer 订阅算倾斜、一个 `CADisplayLink`
  统一驱动所有额外宠物的物理；按配置与会话集合增减数量。

### 7.2 状态机与播放器的解耦

`DSHPetAnimator` 原本在 `-play:` 里硬写 `[[DSHPetPlayer shared] playClipAtURL:…]`，
8 只宠物会抢同一个播放器（表现为只有一只在动、其余定格）。
改法：`-initWithPlayer:` 注入 + `player` 属性，getter 里缺省回落到单例
（保证单宠路径一个字节不变）。

### 7.3 会话从哪来

`/state` **没有**"会话列表"接口，能拿到的只有 notify 事件里的 `sessionId`。
所以 `DSHPetBridge` 维护一个 `sessionMap`：见到 `sessionId` 就 `touch`，
15 分钟没动静就过期。这也意味着**"每只跟一个会话"只认最近真的说过话的会话**——
界面上看得见的行为是：来新消息的会话先长出宠物，会话静默一段时间后宠物自己收掉。

### 7.4 出生与排布（按操作员拍板）

新宠物在**屏幕上方随机 x** 出生（`y = -halfH - 24`，从屏幕外掉进来），
落地后与其它宠物做**轻微排斥**：只沿"更容易分开"的那个轴推，
推力与重叠量成正比、上限 60–80pt。不做刚体碰撞——否则 8 只挤在底部会互弹发疯。

### 7.5 省电

`CADisplayLink` 只在"有宠物在动"时跑：连续 12 帧全部静止就 `invalidate`，
被拖动/抛出/倾斜变化时通过 `DSHPetCrewWakeNotification` 叫醒。
关掉总开关直接 `stop`，不留在后台空转。

## 10. S6d 落地 + 设置面板改纯 UIKit（2026-11-18，v0.1.0-136）

### 10.1 两个硬故障的根因（都在 0.1.0-135 上实测）

**长按菜单「点不动、也关不掉」**

`DSHPetWindow -hitTest:withEvent:` 为了"空白处触摸穿透回桌面"，只放行 `touchTarget`（宠物框）范围内的视图，框外一律 `return nil`。而菜单用的是系统 `UIAlertController`，它的 actionSheet 呈现在**同一窗口**的 rootViewController 上，位置落在宠物框外 → 所有触摸被丢弃。菜单画得出来，但按钮和"取消"都点不到。

同一个坑还顺带吃掉了气泡的点击（展开/收起）。

**设置面板「一片空白」**

包是完整的（可执行文件 166992B、`Info.plist` 有 `NSPrincipalClass`、`Root.plist` 2.4KB、loader entry 174B，全部落在 `var/jb/Library/...`），页面也能推进来，但列表为空 —— `PSListController` 的子类**不会**自动读 bundle 里的 `Root.plist`；上一版补了 `-specifiers` 手动 `loadSpecifiersFromPlistName:@"Root"` 仍然无效。这条私有加载链在 iOS 17 + PreferenceLoader 2.2.8 上不可依赖。

### 10.2 改法

- **窗口命中规则**：`DSHPetWindow` 新增 `touchRoots`（已注册的交互视图：气泡 / 待办面板 / 长按菜单）。`hitTest:` 四段判定：① `self` 或 root.view → nil；② 有 `presentedViewController` → 整窗放行；③ 命中 `touchRoots` 里任一视图的子孙 → 放行；④ 其余按 `touchTarget` 判穿透。
- **菜单自绘**：新增 `DSHPetMenuPanel`（深色圆角、行高 44、标题区 34、宽 240 夹 300 内、0.16s 缩放淡入），最后一项惯例是「取消」（红色、不回调）。`showPetMenu` 改为「已开则收起，长按=开关」，分发到 `showTodoPanel` / `shuffleExpression` / `showBridgeStatus` / `hideForAWhile:3600`。面板一进窗口就注册进 `touchRoots`。
- **面板纯 UIKit 重写**：`DSHPetPrefsRootListController` 从 `PSListController` 子类改成 `UIViewController <UITableViewDataSource, UITableViewDelegate>`，五组由 `DSHPetRow` 模型生成（Switch / Choice / Text / Info / Link），`UITableViewStyleInsetGrouped`，读写走 `CFPreferencesCopyAppValue` / `CFPreferencesSetAppValue`，域仍是 `com.vboxai.littlefatlady.prefs`。不再依赖任何 Preferences 私有类，也不再依赖 `Root.plist`。

### 10.3 踩坑

- `sizePct` 在 dylib 侧是**占屏宽比例**（`fallback:0.30`，夹 0.16–0.62），不是百分数 → 面板 values 必须用 `@0.16 … @0.54` 的小数档，且默认 `@0.30` 必须落在 values 里，否则永远显示第一档。
- `-Werror` 会打未使用的静态函数（`-Wunused-function`）：重写时先删干净再推。
