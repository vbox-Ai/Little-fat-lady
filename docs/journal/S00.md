## 3. 决定

1. **本机无 git，改用 GitHub API 推送**（blobs → tree → commit → PATCH ref）。理由：不装 Git for Windows（要管理员权限、且此机是云电脑），API 推送结果等价（commit 上 GitHub 后可正常 `git clone`）。
2. **S0 不放 Theos 工程**。理由：放了但 CI 编不出 deb，会造成"CI 假绿"；S1 一次性把 `Makefile/control/Tweak.xm/layout` 建齐，CI 那一格才真正跑起来。
3. **仓库不内置素材**（`LICENSE-ASSETS` §3）。CI 与 `check-repo.mjs` 都会挡 `assets/webm|mov|memes`。
4. 阶段闸门四件写死进方案 §20 + `AGENTS.md`，且 `AGENTS.md` 被本工作区自动加载 → 后续每步都会重新看到，不依赖记忆。

## 4. 遗留

- **手机端七条探针未跑**（`NOT RUN`）：需要操作员在手机 NewTerm/SSH 里跑 `scripts/probe/collect-device-env.sh`，把输出贴回来或放进 `docs/imgs/`。阻塞项：无（S1 可先做 Windows 侧编译链验证），但 S1 交付"可装可卸"需要至少 `dpkg -l | grep -i ellekit` 与 rootless 路径判定。

- 余额 provider（`bxfvip` → `unsupported`）留到 S10。
