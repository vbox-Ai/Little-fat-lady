## 1 目标

桌宠不再是"贴在那儿的一张图"：能被拎起来、甩出去、落地弹、侧着手机滑下去。

## 2 实现

- `onPan:` 采样位移/时间得松手速度，>250pt/s 才抛，上限 2400。
- `startPhysicsWithVelocity:` 起 `CADisplayLink`，`stepPhysics:` 用 1/120s 子步积分（重力 / 弹性 / 四边反弹 / 落地摩擦 2.5）。
- 静止判据 `|vy| < 140 && |vx| < 12`，停下即 `clampAndPersist`（省电，不空转）。
- 倾斜重力：`CoreMotion` 30Hz 采样，`physics.tiltGravity` 默认开；`|a| > 0.08` 才认，避免桌面平放抖动。

## 3 这版修的两个真机问题

1. **注销后拉长**：宿主尺寸变了、图层矩形没重算 → 新增 `refreshLayout`，改尺寸后立刻按当前帧重排。
2. **偶发发虚**：`contentsScale` 固定屏幕 scale，图层点宽不是图像宽整数分之一时每帧重采样 → 首帧按 `naturalSize.width / scale` 定宽（1:1），捏合按 1/3 pt 取整。

## 5 踩坑

- `_curFrame` 必须保留强引用，否则 `refreshLayout` 拿到已释放的 CGImage。
- `applyPetWidth:` 里 `round(w*ratio)` 只对齐宽度不对齐高度 → 高度落在半像素上，依旧发虚。
