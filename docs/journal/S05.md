## 1 目标

桌宠不再是"贴在那儿的一张图"：能被拎起来、甩出去、落地弹、侧着手机滑下去。

## 2 实现

- `onPan:` 采样位移/时间得松手速度，>250pt/s 才抛，上限 2400。
- `startPhysicsWithVelocity:` 起 `CADisplayLink`，`stepPhysics:` 用 1/120s 子步积分（重力 / 弹性 / 四边反弹 / 落地摩擦 2.5）。
- 静止判据 `|vy| < 140 && |vx| < 12`，停下即 `clampAndPersist`（省电，不空转）。
- 倾斜重力：`CoreMotion` 30Hz 采样，`physics.tiltGravity` 默认开；`|a| > 0.08` 才认，避免桌面平放抖动。

## 3 这版修的两个真机问题

1. **注销后拉长**：宿主尺寸变了、图层矩形没重算 → 新增 `refreshLayout`，改尺寸后立刻按当前帧重排。
2. **偶发发虚**：`contentsScale` 固定屏幕 scale，图层点宽不是图像宽整数分之一时每帧重采样 → 首帧按 `naturalSize.width / scale` 定宽（1:1），捏合按 1/3 pt 取整。

## 5 踩坑

- `_curFrame` 必须保留强引用，否则 `refreshLayout` 拿到已释放的 CGImage。
- `applyPetWidth:` 里 `round(w*ratio)` 只对齐宽度不对齐高度 → 高度落在半像素上，依旧发虚。

## 8 追加：0.1.0-100（注销后拉长 / 待机偶发糊）

- 根因：`syncLayerFrame` 把 `contentLayer.frame` 铺满宿主后没有按图像比例收回来，`contentsGravity=Resize` 就按图层比例拉伸。
- 真机指纹：**捏一下就好** —— pinch 走 `applyPetWidth` → `refreshLayout` 才重算 rect。
- 修法三条：铺满后立刻重 fit；`setDisplaySize:` 末尾补 `refreshLayout`；fit 比例上限 `1/屏幕scale`（禁止放大）。
- 产物 `v0.1.0-100`：95.58MB，sha256 `7b650420e488662d881694a1b83dbab4c9f74dd8611464d18eb8539a43203ad4`，Release `448077247`。
- 教训写进 MEMORY：铺满宿主的动作必须配一次重 fit。

## 9 追加：0.1.0-102（注销后拉长 / 回缩的真正根因）

- 100 版只补了「铺满后重 fit」一条路径，没修两件根本问题：
  1. `_userSized` 只在内存里 → 每次启动 false → 自动 1:1 定宽把手动尺寸压回 130pt（"放大后注销又变小"）。
  2. `contentsGravity = Resize` 语义就是"填满、可变形" → 任何一帧矩形没算对就当场拉伸。
- 修法：`ui.json` 增 `sizeManual`（捏合时置 YES 并落盘，启动时读回）；`applyPetWidth:` 同步落盘 `size/sizeRatio`；`contentsGravity` 全改 `ResizeAspect`。
- 产物 `v0.1.0-102`：95.58MB，sha256 `bc3a03f2e69e277af39431ff8fca4d6f51263d94be881353d625ba5b1ae693c8`，Release `448109349`。
- 待验：注销后尺寸保持且不拉长；待机 5 分钟不糊；异常时取 `render.jsonl` 的 `pet-aspect` 行。
